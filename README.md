# 📚 Бот расписания

Telegram-бот для автоматической рассылки расписания занятий.
Бот скачивает файлы расписания с Яндекс.Диска, парсит `.docx` и отправляет пользователям расписание в виде файла и удобного текстового сообщения.

**Version 1.03**

---

## ✨ Возможности

- 🔎 **Просмотр расписания** на сегодня, завтра, послезавтра или любую дату
- 🔔 **Авторассылка**: расписание приходит в 7:00 (на сегодня) и в 20:00 (на завтра)
- 👨‍🎓 **Две роли**: студент (по группе) и преподаватель (по ФИО)
- ⏰ Расписание звонков
- 📝 Отправка расписания как документом `.docx`, так и текстом
- 👤 Профиль пользователя: изменение данных, удаление аккаунта, настройка уведомлений
- 💬 Обратная связь разработчику
- 🛡️ Система администрирования с уровнями доступа
- ☁️ Автоматическое скачивание расписания с Яндекс.Диска каждые 5 минут
- 📦 Кэширование расположения файлов для ускорения работы

## 🚀 Команды пользователя

| Команда | Описание |
|---|---|
| `/start` | Запуск бота |
| `/login` | Регистрация (студент / преподаватель) |
| `/help` | Справка по командам |
| `/change` | Список изменений (changelog) |

## 🛡️ Команды администратора

### Уровень 1 — стандартный администратор

| Команда | Описание |
|---|---|
| `/admin` | Список команд администрации |
| `/list_admins` | Список администраторов |

### Уровень 2 — второстепенный администратор

| Команда | Описание |
|---|---|
| `/list_users` | Список всех пользователей |
| `/logs_txt` | Получить логи файлом |
| `/broadcast <текст>` | Рассылка сообщения всем пользователям |
| `/add_admin <ID> <username> <уровень>` | Назначить администратора |
| `/remove_admin <ID>` | Удалить администратора |

### Уровни доступа

- `3` — главный администратор
- `2` — второстепенный администратор
- `1` — стандартный (ограниченный) администратор

> ⚠️ Администратор не может назначить или удалить пользователя с уровнем выше своего.

## 🛠️ Технологии

- **Python 3.11**
- [aiogram 3](https://docs.aiogram.dev/) — Telegram Bot API (диалоги на встроенном FSM: `StatesGroup` + `FSMContext`)
- [APScheduler](https://apscheduler.readthedocs.io/) — планировщик задач (авторассылка, периодическое скачивание)
- [yadisk](https://yadisk.readthedocs.io/) — работа с Яндекс.Диском
- [python-docx](https://python-docx.readthedocs.io/) — парсинг `.docx`
- **SQLite** — хранение пользователей, администраторов и статусов уведомлений
- **Docker** — контейнеризация

## ⚙️ Установка и запуск

### 1. Клонирование

```bash
git clone https://github.com/folov3r/telegram-bot-shedule-.git
cd telegram-bot-shedule-
```

### 2. Создание папок и файла окружения

```bash
mkdir db log schedule
```

Создайте файл `.env` в корне проекта:

```env
TELEGRAM_TOKEN=ваш_токен_бота
YANDEX_TOKEN=ваш_токен_яндекс_диска

# Папка на Яндекс.Диске, где лежит файл расписания (пример: app:/schedule)
YANDEX_DISK_ROOT=app:/
# Имя файла расписания на Диске (пример: schedule.docx)
YANDEX_SCHEDULE_FILENAME=schedule.docx

# Telegram ID главного администратора (берётся у @userinfobot); без него админ не назначится
MAIN_ADMIN_ID=
MAIN_ADMIN_NAME=   # опционально: имя админа для базы данных
```

> Токен бота получается у [@BotFather](https://t.me/BotFather).
> Токен Яндекс.Диска — в [кабинете разработчика Яндекса](https://yandex.ru/dev/disk-api/doc/ru/concepts/quickstart#quickstart__oauth).
> `MAIN_ADMIN_ID` — ваш числовой Telegram ID (можно узнать у бота @userinfobot).

### 3. Запуск через Docker (рекомендуется)

```bash
docker build -t dtk-schedule-bot .
docker run -d --name dtk-bot --env-file .env -v $(pwd)/db:/app/db -v $(pwd)/log:/app/log -v $(pwd)/schedule:/app/schedule dtk-schedule-bot
```

### 4. Запуск без Docker

Требуется **Python 3.12** (на Python 3.14+ не собираются зависимости `lxml`/`pydantic-core`).

```bash
python -m venv venv
source venv/bin/activate   # Linux / macOS
pip install -r requirements.txt
python main.py
```

## 🗄️ База данных

Бот использует три SQLite-базы (создаются автоматически):

- **`users.db`** — `user_id`, `username`, `value` (группа/ФИО), `is_teacher`, `notifications_enabled`
- **`admins.db`** — `user_id`, `username`, `role`, `who_add`
- **`notifications.db`** — статусы уведомлений о новых файлах расписания

## 📌 Частые вопросы

**Бот не присылает расписание автоматически?**
Проверьте, включена ли авторассылка в профиле (кнопка «Авто рассылка»), и что файл расписания загружен на Яндекс.Диск в папку.

**Расписание приходит только файлом, без текста?**
Текстовое расписание доступно только зарегистрированным пользователям (`/login`).
